INTERM

This repository contains the materials (code and datasets) associated with the manuscript:

Title: Intermittent quarantine suppresses epidemic spreading beyond simple contact reduction

Authors: Juliane T. Moraes and Silvio C. Ferreira  

Preprint arXiv. https://doi.org/10.48550/arXiv.2610.00429
  

Repository structure:

- `codes/` — codes used in the analyses.
- `datasets/` — datasets used in the analyses.
